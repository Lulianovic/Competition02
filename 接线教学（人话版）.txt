============================================================
慧灌智控 V1 · 接线教学（人话版）
============================================================
说明：本文件把原来给电脑代理执行的指令，改写成普通人能看懂的接线教学。
核心思路就一句话：先放好所有零件，再按"找元件 → 找它的口 → 接到芯片的某个针脚"的顺序一根根连线。

------------------------------------------------------------
一、先认识主角：STM32F407ZG 这块主控芯片（U1）
------------------------------------------------------------
这块芯片就是整个系统的大脑，上面有很多针脚（引脚）。
我们这次只用到下面这些针脚（千万别接错别的脚）：
  PA0   接土壤湿度传感器（模拟信号）
  PA1   接一个备用可调电压（模拟信号）
  PB0   接温湿度传感器（DHT11）的数据线
  PB8   接光照传感器和屏幕的时钟线（I2C 时钟）
  PB9   接光照传感器和屏幕的数据线（I2C 数据）
  PA9   接串口的接收端（RX）
  PA10  接串口的发送端（TX）
  PC0   接继电器（控制水泵开关）
  PC1   接蜂鸣器
  PC2   接状态指示灯 LED

------------------------------------------------------------
二、需要准备的零件清单（共 17 个）
------------------------------------------------------------
【电源类】
  1. 模拟信号电源（VCC），设为 3.3V，命名为 +3V3 —— 给所有传感器和屏幕供电
  2. 直流电压源，设为 5V，命名为 +5V —— 只给继电器和水泵供电
  3. 电源负极（GND）—— 全图只有一个负极，所有地都接到这一处
  4. 可调电压源，调成 1.65V —— 当作备用模拟量接 PA1

【控制器类】
  5. STM32F407ZG（U1）主控芯片 —— 图里一般已存在，保留即可

【传感器类】
  6. 土壤湿度传感器 YL-69（SEN1）—— 只用 AO 口，DO 口空着不接
  7. 温湿度传感器 DHT11（SEN2）
  8. 光照度传感器 BH1750（SEN3）—— 和屏幕共用一条 I2C 总线

【IO 设备类】
  9. 继电器模块（K1）—— 注意用带 IN 脚那种模块版
  10. 水泵（M1）—— 接在继电器常开触点上
  11. 有源蜂鸣器（BZ1）—— 注意用有源的，别用无源

【LED 类】
  12. LED（D1）—— 状态指示灯

【基础元件类】
  13. 电阻 R1 10kΩ —— 给 BOOT0 下拉到地
  14. 电阻 R2 10kΩ —— 给 NRST 上拉到 3.3V
  15. 电阻 R3 4.7kΩ —— 给 DHT11 数据线上拉（若模块自带可省略）
  16. 电阻 R4 330Ω —— LED 限流
  17. 电容 C1 2.2µF（×2 个）—— 接在 VCAP_1 / VCAP_2 到地之间

【调试助手类】
  18. 串口终端助手（U2）—— 也叫"串口通信助手"

【显示器类】
  19. OLED 显示屏 I2C 128×64（U3）—— 地址 0x3C

提示：在元件库里按上面括号里的"类名"去搜索就能找到对应的零件。

------------------------------------------------------------
三、芯片最小系统（先确认，不新增）
------------------------------------------------------------
以下这些如果图里已经有了，只要核对没问题就行；没有就补上：
  - 把 +3V3 接到芯片的每一个 VDD 脚
  - 把 GND 接到芯片的每一个 VSS 脚
  - 如果芯片有 VBAT 脚，接到 +3V3
  - VCAP_1、VCAP_2 各接一个 2.2µF 电容再到 GND
  - BOOT0 脚经 10k 电阻（R1）连到 GND
  - NRST 脚经 10k 电阻（R2）连到 +3V3

------------------------------------------------------------
四、正式接线（按步骤一步一步来）
------------------------------------------------------------

【第 1 步：串口通信】
  1. 找到"串口终端助手（U2）"这个元件。
  2. 找到它的 RX 口，连到芯片的 PA9 脚（这两根是交叉接的：芯片发 → 助手收）。
  3. 找到它的 TX 口，连到芯片的 PA10 脚（助手发 → 芯片收）。
  4. 把 U2 的 GND 接到总负极 GND。

【第 2 步：土壤湿度传感器 YL-69（SEN1）】
  1. 找到"土壤湿度传感器 YL-69（SEN1）"。
  2. 它的 VCC 口 → 接到 +3V3（注意：一定要 3.3V，千万别接 5V）。
  3. 它的 GND 口 → 接到 GND。
  4. 它的 AO 口 → 连到芯片的 PA0 脚（这就是土壤湿度模拟信号）。
  5. 它的 DO 口 → 什么都不接，悬空放着。

【第 3 步：温湿度传感器 DHT11（SEN2）】
  1. 找到"温湿度传感器 DHT11（SEN2）"。
  2. 它的 VCC 口 → 接到 +3V3。
  3. 它的 GND 口 → 接到 GND。
  4. 它的 DATA 口 → 连到芯片的 PB0 脚。
  5. 从 DATA 口再拉一根线，经过一个 4.7kΩ 电阻（R3）上拉到 +3V3（如果模块自带上拉可以省掉这根）。

【第 4 步：光照传感器 BH1750（SEN3）】
  1. 找到"光照度传感器 BH1750（SEN3）"。
  2. 它的 VCC 口 → 接到 +3V3。
  3. 它的 GND 口 → 接到 GND。
  4. 它的 SCL 口 → 连到芯片的 PB8 脚（这就是 I2C 时钟线）。
  5. 它的 SDA 口 → 连到芯片的 PB9 脚（这就是 I2C 数据线）。
  6. 它的 ADDR 口 → 接到 GND（这样地址才是 0x23，不接会变成别的地址）。

【第 5 步：OLED 屏幕（U3）并入 I2C 总线】
  1. 找到"OLED 显示屏 I2C 128×64（U3）"。
  2. 它的 VCC 口 → 接到 +3V3。
  3. 它的 GND 口 → 接到 GND。
  4. 它的 SCL 口 → 接到和 BH1750 的 SCL 同一个网络上（最终连到芯片 PB8）。
  5. 它的 SDA 口 → 接到和 BH1750 的 SDA 同一个网络上（最终连到芯片 PB9）。
  （记住：屏幕和光照传感器是并在同一条 I2C 总线上的，共用 PB8/PB9。）

【第 6 步：继电器 + 水泵（执行层）】
  1. 找到"继电器模块（K1）"。
  2. 它的 COM 口（公共端）→ 接到 +5V。
  3. 它的 NO 口（常开端）→ 接到水泵（M1）的正极（+）。
     （一定要用常开 NO，不能用常闭 NC，否则一上电就抽水。）
  4. 水泵的负极（−）→ 接到 GND。
  5. 继电器线圈供电：它的 VCC 口 → 接到 +5V；GND 口 → 接到 GND。
  6. 它的 IN 口（控制端）→ 连到芯片的 PC0 脚（这就是控制水泵开关的信号）。

【第 7 步：蜂鸣器（BZ1）】
  1. 找到"有源蜂鸣器（BZ1）"。
  2. 它的正极（+）→ 连到芯片的 PC1 脚（高电平就响）。
  3. 它的负极（−）→ 接到 GND。

【第 8 步：状态指示灯 LED（D1）】
  1. 找到"LED（D1）"。
  2. 芯片的 PC2 脚 → 先经过一个 330Ω 电阻（R4）→ 再接到 LED 的阳极（长脚/正极）。
  3. LED 的阴极（短脚/负极）→ 接到 GND。

【第 9 步：备用可调电压源（PS3）】
  1. 找到"可调电压源（PS3）"，把输出调成 1.65V。
  2. 它的正极（+）→ 连到芯片的 PA1 脚（这就是备用模拟量）。
  3. 它的负极（−）→ 接到 GND。

------------------------------------------------------------
五、接线完成后，用这 5 个最简单的检查确认没接错
------------------------------------------------------------
  1. 土壤湿度线（PA0）、温湿度线（PB0）、光照/屏幕线（PB8/PB9）是否都接到对应脚？
  2. 串口是否交叉接（PA9→RX、PA10→TX）？
  3. 继电器 COM/NO 接 5V 和泵，IN 接 PC0，线圈 VCC/GND 接 5V 和地？
  4. +3V3 和 +5V 是否完全分开、只有 GND 一处相连？
  5. 全图是否只有一个 GND，没有零件随便悬空（YL-69 的 DO 除外）？

------------------------------------------------------------
六、最容易犯的错（千万避开）
------------------------------------------------------------
  - 别把 5V 接到芯片或传感器的 VCC 上，会烧坏或让测量失效。
  - 别把水泵/继电器线圈直接连到芯片脚上，必须经过继电器。
  - 别用继电器的常闭触点（NC）去驱动水泵。
  - 别自己乱加额外的零件（本版只做湿度、温湿度、光照、水泵、串口、屏幕）。
  - 别改芯片那几个固定的针脚（PA0/PA1/PB0/PB8/PB9/PC0/PC1/PC2/PA9/PA10 是固定死的）。
  - 一个针脚上只能接一种信号，别在一条线上并两种不同网络。

------------------------------------------------------------
七、特殊情况处理
------------------------------------------------------------
  A. 找不到 YL-69 传感器怎么办？
     → 用一个"可调电压源"代替：正极接 PA0（仍叫 SOIL_AO 网络），负极接 GND，
        量程设 0～3.3V，用来模拟土壤湿度，并在记录里注明"用可调电压源替代 YL-69"。

  B. 继电器只有线圈两端、没有 IN 脚怎么办？
     → 不能直接用 PC0 驱动，要加一个三极管驱动电路：
        PC0 → 1k 电阻 → NPN 三极管基极；
        三极管发射极 → GND；
        三极管集电极 → 继电器线圈 − 端；
        继电器线圈 + 端 → +5V；
        线圈两端反向并联一个二极管（阴极朝 +5V 方向，用于续流保护）。

  C. 库里找不到某个零件怎么办？
     → 停下来，记下缺哪个零件，上报等指示，不要自己随便找别的型号替代。
